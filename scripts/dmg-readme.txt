sobi (소비마스터) 설치 안내
==========================

1. 설치
   sobi.app 을 옆의 Applications 폴더로 끌어다 놓습니다.

2. 처음 열 때 경고가 뜨면 (한 번만 하면 됩니다)
   이 앱은 Apple 개발자 인증서로 서명되지 않아 처음 열 때
   "Apple은 'sobi'에 악성 코드가 없음을 확인할 수 없습니다" 같은 경고가 뜹니다.
   - [완료]를 누른 뒤 시스템 설정 → 개인정보 보호 및 보안 으로 가서
     아래쪽의 "sobi" 항목 옆 [그래도 열기]를 누르고, 다시 열면 됩니다.
   - "손상되었기 때문에 열 수 없습니다"가 뜨면 터미널에서 아래를 실행한 뒤 다시 엽니다.
       xattr -dr com.apple.quarantine /Applications/sobi.app

3. 연결 설정 (처음 한 번)
   처음 실행하면 아래 설정 파일이 만들어지고, 연결 안내 화면이 나옵니다.
       ~/Library/Application Support/sobi/config.json
   Finder 에서 [이동] → [폴더로 이동…] 에 위 경로를 붙여 넣으면 열 수 있습니다.
   파일의 "database_url" 값에 Supabase 연결 문자열을 넣고 저장한 뒤 앱을 다시 엽니다.
   연결 문자열은 앱 관리자에게 따로 받으세요. 이 파일은 다른 사람과 공유하지 마세요.
